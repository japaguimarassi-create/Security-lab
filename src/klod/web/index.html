Conectar uma máquina própria

Execute o agente em hardware que você controla. O compartilhamento começa desativado e requer autorização do proprietário.

pip install "klod-ai[worker] @ git+https://github.com/japaguimarassi-create/Security-lab.git"
export GPU_MESH_API_URL="https://SEU-DOMINIO"
export GPU_MESH_ACCESS_TOKEN="TOKEN_COPIADO_NO_PAINEL"
export GPU_MESH_SHARE="true"
gpu-mesh-worker

O agente executa somente SHA-256 em CPU, multiplicação de matrizes CUDA e Mandelbrot CUDA. Não aceita scripts ou comandos arbitrários.

Conectar Kaggle Notebooks

Cria kernels privados por tarefa. Configure o usuário e o token da sua conta Kaggle, além do acelerador realmente disponível na conta.

pip install "klod-ai[kaggle] @ git+https://github.com/japaguimarassi-create/Security-lab.git"
export GPU_MESH_API_URL="https://SEU-DOMINIO"
export GPU_MESH_ACCESS_TOKEN="TOKEN_COPIADO_NO_PAINEL"
export KAGGLE_USERNAME="SEU_USUARIO"
export KAGGLE_API_TOKEN="SEU_TOKEN_KAGGLE"
export GPU_MESH_KAGGLE_ACCELERATOR="NvidiaTeslaT4"
export GPU_MESH_SHARE="true"
gpu-mesh-kaggle-worker
Conectar Hugging Face ZeroGPU

Publique primeiro examples/huggingface_zerogpu como um Space Gradio privado e configure o token HF com leitura da quota de uso.

pip install "klod-ai[huggingface] @ git+https://github.com/japaguimarassi-create/Security-lab.git"
export GPU_MESH_API_URL="https://SEU-DOMINIO"
export GPU_MESH_ACCESS_TOKEN="TOKEN_COPIADO_NO_PAINEL"
export HF_TOKEN="SEU_TOKEN_HF"
export GPU_MESH_HF_SPACE_ID="USUARIO/SPACE"
export GPU_MESH_SHARE="true"
gpu-mesh-hf-worker
Conectar sessão Google Colab

Abra o notebook examples/colab/GPU_Mesh_Worker.ipynb no Colab e execute as células. O worker fica online somente enquanto o runtime permanecer ativo.
